About the App

The Study Buddy App is a mobile tool designed to help collegiate students keep track of workloads and school curriculum. Users can create an account to set up an interactive calendar and adjust user preferences. The application features an artificial intelligence tool that can generate study schedules based on user input. Currently only available for Android.
